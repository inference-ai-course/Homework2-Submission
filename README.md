# Class 2 Overview

This folder contains all materials for Class 2 of the Machine Learning Engineer in the Generative AI Era course. It is organized into three main sections: Homework, Lecture, and Project. Each section is designed to help you build foundational skills in transformer architecture, LLM training phases, inference, and fine-tuning.

---

## [Lecture](./lecture/)
- **Focus:** Transformer architecture, attention mechanisms, pretraining, SFT, and alignment
- **Topics Covered:**
  - Transformer and attention mechanisms
  - Next token prediction and hallucination
  - LLM pretraining and data requirements
  - Supervised fine-tuning (SFT)
  - Alignment techniques (DPO, PPO)
  - Test-time scaling (O1, O3)
- **Format:** Step-by-step notebook and markdown explanations

## [Homework](./homework/)
- **Focus:** Assignments and exercises for hands-on practice
- **Topics Covered:**
  - Fundamentals of transformer models
  - Prompt engineering for LLMs
  - Model inference and serving (Hugging Face, vLLM)
  - Data extraction and cleaning (OCR, web scraping)
  - LLM behavior analysis and documentation
- **Instructions:** Complete all sections in the provided notebooks and document your findings.

## [Project](./project/)
- **Focus:** Practical LLM inference, data extraction, and cleaning
- **Tasks Include:**
  1. Running inference with open-source LLMs
  2. Extracting and cleaning data using OCR and web scraping
  3. Comparing outputs and documenting model behavior
  4. Applying prompt engineering techniques for improved results
- **Learning Outcomes:**
  - Understand transformer architecture and LLM training phases
  - Gain hands-on experience with model inference and serving
  - Practice data extraction and cleaning for LLM pipelines
  - Analyze and document LLM outputs and defects

---

## How to Use This Folder
1. **Start with the lecture** to understand the core concepts and techniques.
2. **Complete the homework** to reinforce your learning through practical exercises.
3. **Work on the project** to apply your skills in real-world LLM scenarios.

Each subfolder contains a detailed `README.md` and supporting notebooks. Follow the instructions in each section and use the examples as templates for your own work.

Happy learning!
